## FRONTEND

| Element | Convention |
| :--- | :--- |
| Archivos de componentes | `PascalCase` |
| Enrutamientos | `kebab-case` |
| Archivos de diseño (`layouts`) | `PascalCase` |
| Scripts / Utilidades | `kebab-case` |
| Colecciones de contenido (Carpetas en `content`) | `kebab-case` |
| Archivos de esquema | `camelCase` |
| Variables de entorno | `UPPER_SNAKE_CASE` |

## BACKEND

| Element |  Convention  |
| :--- | :--- |
| Carpetas | `Pascal_Snake_Case` |
| Archivos | `snake_case` |
| Clases | `PascalCase` |
| Constantes | `SCREAMING_SNAKE_CASE` |
| Métodos / Funciones | `snake_case` |
| Variables | `snake_case` |
