# UN-Budget

Web application designed and developed as an academic project to provide the end user with a digital platform where they will be able to manage their personal finances by tracking expenses against monthly personal budgets, which are divided into several categories. Moreover, the application will create reports for the user to visualize their financial health, so that they can make informed decisions based on their balance.

**An academic project done for the subject 'Ingeniería de Software I'**.
